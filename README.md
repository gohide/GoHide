## What it does

Press one global hotkey and the windows, taskbar buttons and tray icons you chose disappear — nothing flashes on screen, nothing lingers in Alt-Tab, no icon left behind. Press it again and everything comes back exactly where it was. Great for focus, screen-sharing, presentations and privacy.

Most "window hiders" leave a tray icon or a taskbar button behind. gohide removes every trace you choose — and restores it cleanly — even on the latest Windows 11, where other tools quietly give up.

## Features

- **Hide windows & taskbar entries** — remove an app's windows and its taskbar button in one move; nothing lingers in Alt-Tab.
- **Hide system-tray icons** — the part most tools get wrong. Works on the latest Windows 11.
- **Global hotkeys** — one hotkey hides everything at once; per-app hide/show hotkeys too. System-wide, even when gohide sits in the tray.
- **Restore all at once** — everything returns exactly where it was; nothing gets stranded.
- **Mute or suspend while hidden** — silence a hidden app, or pause its process so a background game stops eating CPU/GPU (suspend is Pro).
- **Privacy cover screen** (Pro) — the moment you hide everything, a full-screen cover (plain dark or any image) drops over the desktop.
- **Dynamic selection** (Pro) — hide apps by window title or class instead of picking each one.
- **Start with Windows, elevated** — via a Task Scheduler task, no UAC prompt on every boot.
- **English & 简体中文** — follows your Windows language automatically.
- **Light and private** — no account, no telemetry, works fully offline.
